Cómo funciona

Un comando. Un sitio.

Escribís tus páginas en HTML, referenciás los componentes con un comentario especial, y StaticFlow se encarga del resto.

pages/index.html

<body>
  <!-- @import header -->

  <main>
    <h1>Hola mundo</h1>
  </main>

  <!-- @import footer -->
</body>

Terminal

# Modo desarrollo
npm start

# Build para producción
npm run build

# Resultado en public/
→ public/index.html ✅

Estructura

Todo en su lugar

Una estructura de carpetas simple y predecible. Nada mágico.

mi-sitio/
├── _components/    # header.html, footer.html, ...
├── pages/          # index.html, about.html, blog/index.html
├── assets/         # css/, js/, imágenes
├── public/         # salida generada (no versionar)
└── staticflow.js   # el motor
