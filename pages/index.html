Cómo funciona

Un comentario. Un componente.

Escribís tus páginas en HTML, referenciás los componentes con <!-- @import nombre -->, y StaticFlow los resuelve recursivamente antes de generar el sitio.

pages/index.html

<!DOCTYPE html>
<html lang="es">
<body>
  <!-- @import header -->

  <main>
    <h1>Hola mundo</h1>
  </main>

  <!-- @import footer -->
</body>
</html>

Terminal

# Modo desarrollo con livereload
npm start

# Build para producción (minificado)
npm run build

# Resultado
📦 3 páginas compiladas
✅ Build completo en 12ms

Estructura

Todo en su lugar

Una carpeta por responsabilidad. Sin archivos de configuración de terceros, sin node_modules con 200 MB de dependencias.

mi-sitio/
├── _components/
│   ├── header.html
│   └── footer.html
├── pages/
│   ├── index.html
│   ├── about.html
│   └── blog/
│       └── index.html
├── assets/
│   ├── css/styles.css
│   └── js/main.js
├── public/          # generado, no versionar
├── lib/             # módulos del motor
├── staticflow.js
└── staticflow.config.js
_components/
Fragmentos HTML reutilizables. Cualquier archivo .html aquí se puede importar con <!-- @import nombre -->.
pages/
Cada archivo se compila en una página del sitio. Las subcarpetas se preservan en public/.
assets/
CSS, JS, imágenes. Se copian tal cual a public/assets/.
public/
Salida del build. No versionar — se regenera en cada build.
staticflow.config.js
Configuración opcional del motor (puerto, minificación, etc.).

Configuración

staticflow.config.js

Configurá el motor con un archivo de configuración en la raíz. Los valores del archivo sobreescriben los defaults, y los argumentos de CLI tienen la prioridad más alta.

// staticflow.config.js
module.exports = {
  port:    3000,      // puerto del servidor de desarrollo
  verbose: true,      // mostrar mensajes en consola
  minify:  false,     // minificar HTML, CSS y JS en el build

  // avanzado (raramente necesario cambiar)
  components: '_components',
  pages:      'pages',
  output:     'public',
  assets:     'assets',
};

La precedencia es: defaults ← staticflow.config.js ← args de CLI.
