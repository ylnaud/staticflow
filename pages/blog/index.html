Proyectos

¿Qué podés construir?

StaticFlow es una base minimalista para cualquier sitio que no necesite un servidor dinámico. Estos son algunos casos de uso comunes.

✍️

Blog personal

Escribí tus artículos en HTML puro, usá un componente de header/footer común y publicá sin configurar nada. Cada post es un archivo .html en pages/blog/.

HTML CSS Componentes
🎨

Portfolio

Mostrá tus proyectos con un diseño limpio y carga instantánea. Ideal para diseñadores y desarrolladores que quieren una presencia web sin overhead.

HTML CSS Grid Assets
🚀

Landing page

Página de lanzamiento o captura de leads. Con el servidor de desarrollo y livereload, iterás el diseño en tiempo real sin recargar manualmente.

HTML CSS JS mínimo
📚

Documentación técnica

Docs para tu librería o herramienta. Navegación por componentes, bloques de código con botón de copiar, y estructura de carpetas que refleja la jerarquía del sitio.

HTML semántico Componentes CopyCode JS
🛍️

Landing de producto

Presentación de un producto o servicio. Precios, características, CTA y testimonios en una sola página optimizada para conversión.

HTML CSS custom props SmoothScroll
📅

Página de evento

Countdown, agenda, speakers y registro. Contenido que cambia poco pero necesita verse bien en mobile, tablet y desktop sin un framework pesado.

HTML Responsive CSS JS modular
